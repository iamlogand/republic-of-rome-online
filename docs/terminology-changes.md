# Terminology changes

This document explains terminology used in this implementation that differs from the original board game.

## Below minimum force → Risky command

The term "below minimum force" has been replaced with "risky command". Since players no longer need to do the combat calculations themselves, a more thematic term makes sense.

## Drought → Famine

The term "drought" has been replaced with "famine". Droughts are natural occurrences that aren't caused by humans. However, in this game, warfare can trigger a drought. Famines are more fitting since they were often caused by droughts or war.

## Eliminate forces → Disband forces

The term "eliminate forces" has been replaced with "disband forces". The senate can only vote to stand down legions and fleets that are sitting in the reserve, so "disband" describes what happens more plainly than "eliminate", which suggests they were destroyed by an enemy. Note that the original game also uses "disbandment" for the separate advanced rule that lets a victorious commander stand down his own veteran legions ([2.04.2](../game-data/rules/02-advanced-game/2.04-legionary-disbandment-recall.md#2.04.2)).
